🎙️ Call Audio — Atur Volume

Slider volume 0-100% pakai Helper.setSpeakerphoneOn + gain. Mute, speaker/earpiece, pindah ke VideoCall tanpa putus via addTrack + renegotiate.

📹 Video — Filter & Share Screen

Filter via ColorFiltered (Warm/Cool/B&W/Beauty). Screen Share pakai getDisplayMedia + replaceTrack. PIP local bisa drag. Switch kamera depan/belakang.

💬 Chat WA-Level

View Once (folder Cloudinary view_once), Edit/Hapus, Love ❤️, Swipe Reply, Typing/Recording/Online via presence/{uid}, Centang 1/2 biru via status.

🎂 Auto Ultah 00:00

Tanpa Cloud Functions! Pakai flutter_local_notifications.zonedSchedule timezone Asia/Makassar. Trigger tiap tahun + banner di Home.

🖼️ Storage No CC

Firebase Storage butuh CC → pakai CloudinaryService unsigned preset. Auto compress ke WebP 80%, 1080px. 25GB gratis = 17 tahun untuk 2 orang.

📱 Support DPI & 120Hz

flutter_displaymode setHighRefreshRate, asset 1080px auto scale ke xxhdpi/No DPI. MediaQuery.textScaler linear 1.0 biar ga pecah.

🛠️ Cara Jalanin (No CC) WebP dari 6.9MB → 216KB (96% hemat)

1. flutterfire configure (Spark Free, JANGAN aktifkan Storage)
2. Daftar cloudinary.com (email doang) → Settings > Upload > Create Unsigned Preset dykal_unsigned → Copy Cloud Name ke lib/config/app_constants.dart
3. flutter pub get && flutter run
4.Firestore rules: allow read, write: if request.auth != null
5. Untuk ilustrasi: sudah ada di assets/illustrations/webp/ siap pakai, transparan background, ringan.
